# 每日新增趋势

本机“全部记忆”总览提供可收起的柱状图，默认最近 14 天，可切换 30 天。默认显示日常新增，勾选后显示历史导入；悬停可查看当天数字，也可展开文字表格。

## 统计口径

按北京时间（Asia/Shanghai）记录每条记忆第一次生效的日期，而不是最后编辑时间或原始聊天发生日期。待确认且从未生效的内容不计入；后续编辑、合并、移出和重新加入不会再产生一次新增。已经生效后又移出的记录仍属于当时的新增，因此趋势表示新增量，不表示当前有效数量或净增长。

会话补录及备份恢复单独列为历史导入。批量补录按实际首次生效时间归档，不根据原始陈述时间虚构过去的新增；备份恢复保留备份中的版本时间。日常采集可以先单独查看，避免导入峰值压缩普通日期的柱子。

总览统计整个用户的知识库，不跟随下方列表搜索或类型筛选；项目和全局分栏中隐藏这张总览卡。

## 成熟组件与本地运行

使用固定版本 [Chart.js 4.6.1](https://www.chartjs.org/docs/latest/getting-started/integration.html) 的 UMD 构建。构建时从 npm 官方 registry 获取，校验包的 SHA-512 integrity，记录实际静态文件 SHA-256；运行时从本机 /assets 加载，无 CDN 或额外网络请求。

Chart.js 与捆绑 @kurkle/color 的 MIT 许可证保留在发行资源中。组件版本、来源和校验值见 chart-vendor.json。原生 canvas 配有可访问名称、文本汇总和每日数字表，参考 [官方可访问性说明](https://www.chartjs.org/docs/latest/general/accessibility.html)。

## 接口与验证

GET /v1/stats/daily?days=14 需要现有用户认证，返回固定 1–90 天的零填充日序列、当日值和区间总值；每一天仅含 date、regular、imported，不返回记忆内容或其他用户数据。

统计只读取当前用户的权威 SQLite 版本记录，使用首次生效的部分索引；不调用模型、不改变记忆。前端缓存同一窗口和计数状态 30 秒，新增状态变化或切换时间窗口后更新。

测试覆盖北京时间跨日、候选转生效、重复写入、编辑、遗忘与恢复、补录归类、未来日期、用户隔离、备份恢复和参数上限。实际浏览器验收分别检查真实 API 数值、历史开关、14/30 天、悬停提示、收起展开、空库、手机布局与外部请求。
