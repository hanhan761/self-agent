# 每日注入 Token 估算

总览在每日新增记忆图下方提供第二张柱状图，14／30 天与第一张图同步。按北京时间统计当前 Windows 用户 Codex 会话日志里，以 Self Agent 记忆标记开头的 developer 消息；以会话 ID、消息 ID 和片段序号去重，使用离线 tiktoken o200k_base 对每条文本计算一次。

这个数字是估算，不是模型实际计费或额度用量：gpt-6.1-terra 的分词映射未确认；文本在后续请求中重复携带、缓存命中、消息协议开销都无法从现有日志归因。历史会话分叉与测试可能重复；不含 Claude Code 与交晓智。目录不可读时页面提示部分记录不全。

首次查看会增量读取用户的本机 Codex 会话日志及归档，后续只处理追加内容。仅本机知识库所有者可访问统计接口；SQLite 投影只保存日期、数字、事件和文件标识的摘要及扫描游标，不保存对话正文或凭据。投影在本机数据目录，可从现存日志重建；清理原始会话日志后不可凭空恢复。

离线词表需按 local-build.md 放入 runtime/models/tokenizers，构建器检查 SHA-256；词表、分词器或权限不可用时显示统计不可用，不展示虚构的零值。当前公开安装包不会因源码更新自动变化。
